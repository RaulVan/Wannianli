# 经验

- 2026-09-19：用户截图指出菜单栏面板越过屏幕顶部且与主窗口外观不一致。菜单栏 UI 必须在显示前确定尺寸，按状态栏按钮所在屏幕约束位置，并验证实际屏幕坐标；不能只截取完整窗口图就认为定位正确。面板应跟随应用外观，而非状态栏继承的外观。
- 2026-09-19：安装包静态默认 AppIcon 使用数字 12；运行时才按系统当天日期替换。
- 2026-09-19：菜单栏面板的收起不能只依赖再次点击状态栏图标；需要覆盖点击面板外部、应用切换失焦和 Esc，并在面板关闭后清理事件监听。
- 2026-09-19：应用对外中文名称固定为“万年历”，包括 `.app` 产物、可执行文件和进程名称；Swift 模块名可保留稳定的 `Wannianli`，避免中文产品名影响源码导入。
- 2026-09-19：Dock 图标必须检查实际像素 alpha，PNG 文件具有 RGBA 通道不代表背景透明；静态 AppIcon 与运行时动态日期使用的基础图都要验证角点 alpha 为 0。
- 2026-09-19：测试固定日期不能仅传日号或在 `--ui-testing` 下隐式启用，否则验收进程可能把真实“今天”显示为测试日期。固定日期必须使用显式完整 ISO 日期参数，普通启动始终读取系统当天。
- 2026-09-20：月历的鼠标拖动与触控板双指滚动是独立交互契约；用户要求双指方向互换时，只调整滚动手势的月份增减映射，不连带改变鼠标拖动方向。
- 2026-09-20：菜单面板加入动态内容时不能通过压缩月历给内容让位；月历应维持稳定高度，面板优先随内容增长，达到屏幕上限后只滚动动态事件区域。
- 2026-09-20：月份网格不能只设置列宽后再叠加按钮 padding，否则两位数月份的实际文本宽度会被压缩换行；年月选择项必须明确单行约束、稳定点击尺寸和选中态，主窗口与菜单面板复用同一交互契约。
- 2026-09-20：根据 `@Published` 的变化即时调整 AppKit 容器尺寸时，回调内必须使用发布携带的新值；发布发生在属性写入前，重新读取 ObservableObject 会得到旧事件数并把动态内容区域裁为零高度。
